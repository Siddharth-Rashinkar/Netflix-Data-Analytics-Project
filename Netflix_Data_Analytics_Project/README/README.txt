# Netflix Data Analytics Project

## Project Overview
This project analyzes Netflix movies and TV shows data using Python, SQL, and Power BI. The objective of this project is to perform data cleaning, exploratory data analysis (EDA), SQL analysis, and build an interactive Power BI dashboard to generate business insights from the Netflix dataset.

---

## Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- MySQL Workbench
- Power BI
- Jupyter Notebook

---

## Dataset Information
Dataset Name:
netflix_titles.csv

The dataset contains information about:
- Movies
- TV Shows
- Directors
- Cast
- Countries
- Ratings
- Genres
- Release Year
- Duration
- Date Added

---

## Project Workflow

### 1. Data Collection
- Imported Netflix dataset CSV file.

### 2. Data Cleaning (Python)
Performed:
- Handling missing values
- Removing duplicate records
- Date format conversion
- Feature engineering
- Data preprocessing

### 3. Exploratory Data Analysis (EDA)
Analyzed:
- Movies vs TV Shows
- Top 10 Countries
- Ratings Distribution
- Content Added Over Years
- Genre Analysis
- Release Trends

### 4. SQL Analysis
Performed SQL queries for:
- Content count
- Top countries
- Rating analysis
- Year-wise analysis
- Filtering movies and TV shows
- Trend analysis

### 5. Power BI Dashboard
Created interactive dashboard with:
- KPI Cards
- Bar Charts
- Donut Charts
- Line Charts
- Treemap
- Slicers

---

## Key Insights
- Movies dominate Netflix content compared to TV Shows.
- United States has the highest Netflix content.
- Netflix content increased rapidly after 2015.
- TV-MA is the most common rating category.
- Drama and International Movies are highly popular genres.
